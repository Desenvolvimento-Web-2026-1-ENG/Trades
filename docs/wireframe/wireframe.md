# 🛡️ Wireframe — Trades: O Hub dos Colecionadores

## 📌 Sobre o Projeto

O Trades é uma plataforma desenvolvida para colecionadores de itens como cartas Pokémon, selos, moedas e outros colecionáveis. O sistema permite o gerenciamento de inventários pessoais e a realização de trocas entre usuários de forma organizada e segura.

O objetivo do wireframe é apresentar a estrutura visual inicial do sistema, demonstrando a organização das telas, navegação e funcionalidades principais da aplicação antes da etapa de desenvolvimento.

# 📌 Considerações Finais

O wireframe foi desenvolvido com foco em organização, usabilidade e facilidade de navegação para os usuários da plataforma. A prototipagem auxilia na visualização inicial do sistema e serve como base para o desenvolvimento front-end e back-end do projeto.

## 💻 Tecnologias Previstas

- Front-end: HTML, CSS e JavaScript
- Back-end: Arquitetura Monolítica MVC
- Banco de Dados: MySQL/PostgreSQL
- Versionamento: Git e GitHub
